§2 if / else — το πρόγραμμα αποφασίζει

      
Στα λούνα παρκ υπάρχει ένα ταμπελάκι στο τρενάκι: «Πρέπει να είσαι πάνω από 1.20 για να ανέβεις». Αυτό είναι μια απόφαση με δύο δρόμους. Στην Python γράφεται έτσι:


      
print("Welcome to the rollercoaster!")
height = int(input("What is your height in cm? "))

if height >= 120:
    print("You can ride the rollercoaster!")
else:
    print("Sorry, you have to grow taller before you can ride.")


      
Τρία πράγματα που πρέπει να δεις

      
    
        
  • Η άνω-κάτω τελεία : στο τέλος της γραμμής με το if και το else. Χωρίς αυτήν, τίποτα.
    • 
        
  • Η εσοχή (indentation) — τέσσερα κενά. Ό,τι είναι μέσα, ανήκει στο if. Ό,τι ξαναγυρίζει στην αρχή της γραμμής, τρέχει ούτως ή άλλως. Αυτό λέγεται code block.
    • 
        
  • Το else δεν έχει συνθήκη. Σημαίνει απλώς «σε κάθε άλλη περίπτωση».
    • 
      


      
Οι τελεστές σύγκρισης

      

        
ΤελεστήςΣημαίνειΠαράδειγμα

        
          
>μεγαλύτερο από7 > 3 → True

          
<μικρότερο από7 < 3 → False

          
>=μεγαλύτερο ή ίσο120 >= 120 → True

          
<=μικρότερο ή ίσο5 <= 4 → False

          
==ίσο με (δύο ίσον!)3 == 3 → True

          
!=διαφορετικό από3 != 4 → True

        
      


      

        
Το λάθος που θα κάνεις σίγουρα: if age = 18: με ένα ίσον. Το ένα = δίνει τιμή. Το == ρωτάει αν είναι ίσα. Η Python θα σου βγάλει SyntaxError — και τώρα ξέρεις γιατί.

      


      
Πρόβλεψε πριν τρέξεις

      
Τι θα τυπώσει το παρακάτω αν ο χρήστης γράψει 120; Και αν γράψει 119; Πες το δυνατά, μετά τρέξ' το.

      
height = int(input("Height in cm: "))

§3 Το modulo — «τι περισσεύει;»

      
Το % το είδες την Ημέρα 2: δίνει το υπόλοιπο μιας διαίρεσης. Σήμερα γίνεται χρήσιμο. Ένας αριθμός είναι ζυγός αν, όταν τον διαιρέσεις με το 2, δεν περισσεύει τίποτα.


      
print(10 % 2)    # 0   → το 10 είναι ζυγό
print(7 % 2)     # 1   → το 7 είναι μονό
print(15 % 5)    # 0   → το 15 διαιρείται ακριβώς με το 5
print(17 % 5)    # 2


      
number = int(input("Which number do you want to check? "))

if number % 2 == 0:
    print("This is an even number.")
else:
    print("This is an odd number.")


      

        
Ο κανόνας: x % y == 0 σημαίνει «το x διαιρείται ακριβώς με το y». Θα το χρειαστείς για τα δίσεκτα έτη σε λίγο — και σε δεκάδες προγράμματα μετά.

§5 Nested if & elif — περισσότεροι από δύο δρόμοι

      
Το τρενάκι τώρα χρεώνει ανάλογα με την ηλικία. Αυτό είναι μια απόφαση μέσα σε μια άλλη απόφαση: πρώτα «μπορείς να ανέβεις;», και μόνο αν ναι, «πόσο πληρώνεις;».


      
print("Welcome to the rollercoaster!")
height = int(input("What is your height in cm? "))

if height >= 120:
    print("You can ride the rollercoaster!")
    age = int(input("What is your age? "))
    if age < 12:
        print("Child tickets are €5.")
    elif age <= 18:
        print("Youth tickets are €7.")
    else:
        print("Adult tickets are €12.")
else:
    print("Sorry, you have to grow taller before you can ride.")


      
Πώς διαβάζεται το elif

      
Η Python ελέγχει τις συνθήκες με τη σειρά, από πάνω προς τα κάτω, και σταματάει στην πρώτη που είναι αληθής. Οι υπόλοιπες δεν εξετάζονται καθόλου.

      
    
        
  • Αν age = 9 → age < 12 είναι αληθές → «Child» και τέλος.
    • 
        
  • Αν age = 15 → age < 12 ψευδές, age <= 18 αληθές → «Youth».
    • 
        
  • Αν age = 40 → τίποτα από τα δύο → else → «Adult».
    • 
      

      
Πρόσεξε: στο elif age <= 18 δεν χρειάζεται να γράψεις «και μεγαλύτερος από 12». Αν έφτασε εκεί, ήδη ξέρουμε ότι δεν ήταν μικρότερος από 12.


      

        
Ζωγράφισέ το. Πριν γράψεις ένα πρόγραμμα με πολλά if, σχεδίασε στο χαρτί ένα διάγραμμα ροής: ρόμβοι για τις ερωτήσεις, βέλη «ναι» / «όχι», ορθογώνια για τις ενέργειες. Οι επαγγελματίες το κάνουν ακόμα. Για ένα άτομο που σχεδιάζει, είναι το πιο φυσικό εργαλείο προγραμματισμού που υπάρχει.

      


      
Το δίσεκτο έτος — τρία επίπεδα βάθους

      
Ένα έτος είναι δίσεκτο αν διαιρείται με το 4 — εκτός αν διαιρείται και με το 100 — εκτός αν διαιρείται και με το 400. Το 2000 ήταν δίσεκτο. Το 1900 όχι. Το 2024 ναι.

      
Πριν δεις τον κώδικα στις ασκήσεις, δοκίμασε να ζωγραφίσεις το διάγραμμα ροής μόνος σου. Τρεις ρόμβοι, ο ένας μέσα στον άλλο.

    


    


    
    

      
§6 Πολλά if στη σειρά — όταν θέλεις όλα να ελεγχθούν

      
Το elif σταματάει στην πρώτη αληθή συνθήκη. Μερικές φορές όμως θέλεις κάθε συνθήκη να ελεγχθεί ξεχωριστά — π.χ. στην πίτσα, μπορείς να θέλεις και πεπερόνι και έξτρα τυρί. Δεν είναι «ή το ένα ή το άλλο».


      
print("Welcome to Python Pizza Deliveries!")
size = input("What size pizza do you want? S, M, or L ")
add_pepperoni = input("Do you want pepperoni? Y or N ")
extra_cheese = input("Do you want extra cheese? Y or N ")

bill = 0

if size == "S":
    bill += 15
elif size == "M":
    bill += 20
else:
    bill += 25

if add_pepperoni == "Y":
    if size == "S":
        bill += 2
    else:
        bill += 3

if extra_cheese == "Y":
    bill += 1

print(f"Your final bill is: €{bill}.")


      
Δες τη διαφορά: το μέγεθος είναι if / elif / else — μία επιλογή από τρεις. Το πεπερόνι και το τυρί είναι ξεχωριστά if — καθένα ελέγχεται ανεξάρτητα.


      

        
Νέο σύμβολο: το bill += 15 είναι συντομογραφία του bill = bill + 15. «Πρόσθεσε 15 σε ό,τι έχει ήδη το bill». Θα το βλέπεις παντού.

      


      

        
Θέλω…Χρησιμοποιώ

        
          
μία επιλογή από πολλές (μέγεθος, κατηγορία ηλικίας)if / elif / else

          
πολλές ανεξάρτητες επιλογές που μπορεί να ισχύουν μαζί (extras)πολλά if στη σειρά

        
      

    


    


    
    

      
§7 Logical operators — and, or, not

      
Μερικές φορές μια απόφαση χρειάζεται δύο συνθήκες ταυτόχρονα. Αντί να φωλιάζεις if μέσα σε if, τις ενώνεις:


      

        
ΤελεστήςΑληθές όταν…Παράδειγμα

        
          
andκαι οι δύο συνθήκες είναι αληθείςage >= 45 and age <= 55

          
orτουλάχιστον μία είναι αληθήςscore < 10 or score > 90

          
notη συνθήκη είναι ψευδής (το αντιστρέφει)not is_raining

        
      


      
a = 7
print(a > 5 and a < 10)     # True  — και τα δύο ισχύουν
print(a > 5 and a > 10)     # False — το δεύτερο δεν ισχύει
print(a > 5 or a > 10)      # True  — αρκεί το ένα
print(not a > 5)            # False — το αντίστροφο του True


      
Στο τρενάκι, ας πούμε ότι όσοι είναι 45 έως 55 ετών ανεβαίνουν δωρεάν «γιατί περνούν κρίση μέσης ηλικίας»:

      
if age < 12:
    print("Child tickets are €5.")
elif age <= 18:
    print("Youth tickets are €7.")
elif age >= 45 and age <= 55:
    print("Everything is going to be ok. Have a free ride on us!")
else:
    print("Adult tickets are €12.")


      

        
Παγίδα: στα ελληνικά λέμε «αν είναι 3 ή 5». Στην Python δεν γράφεις if x == 3 or 5. Γράφεις if x == 3 or x == 5. Κάθε πλευρά του or πρέπει να είναι ολόκληρη σύγκριση.

§9 Project — Treasure Island

      
Ένα παιχνίδι «διάλεξε τη δική σου περιπέτεια». Ο παίκτης παίρνει αποφάσεις, και κάθε απόφαση οδηγεί σε άλλο μονοπάτι. Όλο το παιχνίδι είναι if μέσα σε if.


      
Βήμα 0 — το χαρτί πριν τον κώδικα

      
Πάρε ένα Α4. Σχεδίασε την ιστορία σου ως διάγραμμα ροής: πού ξεκινάει ο παίκτης, τι επιλογές έχει, πού τον βγάζει η καθεμία. Τουλάχιστον τρεις αποφάσεις σε βάθος, τουλάχιστον ένας τρόπος να κερδίσεις και τρεις να χάσεις. Αυτό είναι το μισό project — και είναι το μισό που κάνει ένας game designer.


      
Βήμα 1 — η εισαγωγή

      
Με τρία μονά εισαγωγικά ''' μπορείς να τυπώσεις πολλές γραμμές μαζί. Το r μπροστά λέει στην Python «πάρε τις ανάποδες καθέτους \ όπως είναι» — αλλιώς τις μπερδεύει με ειδικούς χαρακτήρες. Ιδανικό για ASCII art. Ζωγράφισε δικό σου — ένα νησί, ένα κάστρο, ό,τι ταιριάζει στην ιστορία σου.

      
print(r'''

choice1 = input('You are at a crossroad. Where do you want to go? Type "left" or "right".\n').lower()

    if choice2 == "wait":

Το τελευταίο else πιάνει ό,τι δεν περιμέναμε — αν ο παίκτης γράψει «πράσινη». Ένα καλό πρόγραμμα δεν σκάει ποτέ επειδή ο χρήστης έγραψε κάτι περίεργο.

Love Calculator

            
Ζήτα δύο ονόματα. Μέτρησε πόσες φορές εμφανίζονται τα γράμματα της λέξης TRUE και στα δύο μαζί, και πόσες τα γράμματα της LOVE. Κόλλησε τους δύο αριθμούς σε έναν διψήφιο. Κάτω από 10 ή πάνω από 90: «you go together like coke and mentos». 40–50: «you are alright together». Αλλιώς μόνο το σκορ.

r = combined.count("r")
u = combined.count("u")
e = combined.count("e")
true = t + r + u + e

l = combined.count("l")
o = combined.count("o")
v = combined.count("v")
love = l + o + v + e

score = int(str(true) + str(love))

if score < 10 or score > 90:
    print(f"Your score is {score}, you go together like coke and mentos.")
elif score >= 40 and score <= 50:

else:
    print(f"Your score is {score}.")

§11 Turtle — διάλεξε σχήμα

      
Η χελώνα ρωτάει τον χρήστη τι να ζωγραφίσει, και αποφασίζει με if.


      

      
import turtle

shape = input("What shape? triangle, square or star: ").lower()
colour = input("What colour? ")

pen = turtle.Turtle()
pen.pensize(4)
pen.color(colour)

if shape == "triangle":
    pen.forward(120)
    pen.left(120)
    pen.forward(120)
    pen.left(120)
    pen.forward(120)
elif shape == "square":
    pen.forward(100)
    pen.left(90)
    pen.forward(100)
    pen.left(90)
    pen.forward(100)
    pen.left(90)
    pen.forward(100)
elif shape == "star":
    pen.forward(150)
    pen.right(144)
    pen.forward(150)
    pen.right(144)
    pen.forward(150)
    pen.right(144)
    pen.forward(150)
    pen.right(144)
    pen.forward(150)
else:
    pen.write("I don't know that shape!", font=("Arial", 16, "normal"))

turtle.done()


      

        
Δικό σου τώρα. Πρόσθεσε ένα τέταρτο σχήμα. Άλλαξε το τι ελέγχει ο χρήστης — το μέγεθος; το πάχος; Κάνε το πρόγραμμα να ζωγραφίζει δύο σχήματα αν ο χρήστης γράψει «both». Και παρατήρησε κάτι: το αστέρι είναι πέντε φορές οι ίδιες δύο γραμμές. Την Ημέρα 5 θα μάθεις να το γράφεις σε δύο γραμμές αντί για δέκα.

      

    


    


    
    

      
§12 AI Corner — το πρώτο chatbot ήταν ένα σωρό if

      
Το 1966 ένας καθηγητής στο MIT έφτιαξε την ELIZA, το πρώτο πρόγραμμα που «συζητούσε». Ο κόσμος ενθουσιάστηκε. Κάποιοι νόμιζαν ότι τους καταλάβαινε. Δεν καταλάβαινε τίποτα — ήταν μια σειρά από κανόνες: αν η πρόταση περιέχει τη λέξη «μητέρα», απάντησε «Πες μου για την οικογένειά σου».

      
Με όσα έμαθες σήμερα, μπορείς να φτιάξεις μια μίνι ELIZA σε δέκα γραμμές:


      
message = input("Tell me something: ").lower()

if "hello" in message or "hi" in message:
    print("Hello! How are you feeling today?")
elif "sad" in message or "tired" in message:
    print("I'm sorry to hear that. What happened?")
elif "happy" in message or "great" in message:
    print("That's wonderful! Tell me more.")
elif "?" in message:
    print("Why do you ask?")
else:
    print("I see. Go on.")


      
Το in είναι καινούριο: ρωτάει «υπάρχει αυτή η λέξη μέσα στο κείμενο;» και δίνει True ή False. Πρόσθεσε πέντε δικούς σου κανόνες. Μετά δοκίμασε να το «σπάσεις» — γράψε κάτι που το μπερδεύει.


      

        
Η ερώτηση που μετράει: Πόσα elif θα χρειαζόσουν για να καταλαβαίνει το chatbot οποιαδήποτε πρόταση; Χίλια; Ένα εκατομμύριο; Δεν φτάνουν ποτέ. Αυτός είναι ο λόγος που η σύγχρονη AI δεν είναι ένας τεράστιος σωρός από if. Αντί να γράφει κάποιος τους κανόνες, ο υπολογιστής τους βρίσκει μόνος του από εκατομμύρια παραδείγματα. Αυτό λέγεται machine learning, και θα το δούμε από κοντά αργότερα μέσα στη χρονιά.

        
Παίξε πέντε λεπτά Akinator. Το τζίνι μαντεύει τον χαρακτήρα που σκέφτεσαι κάνοντας ερωτήσεις ναι/όχι. Είναι ένα γιγάντιο διάγραμμα ροής — ακριβώς ό,τι ζωγράφισες σήμερα, με εκατομμύρια ρόμβους.

      

    


    


    
    

      
§13 Συχνά λάθη

      
Όταν σκάσει κάτι, ψάξ' το εδώ πρώτα.

      

        
ErrorΤι φταίει

        
          
SyntaxError στο ifΞέχασες την άνω-κάτω τελεία : στο τέλος — ή έγραψες = αντί για ==.

          
IndentationErrorΗ γραμμή κάτω από το if δεν έχει εσοχή, ή έχει διαφορετική από τις διπλανές της. Τέσσερα κενά, πάντα.

          
TypeError: '>' not supported between 'str' and 'int'Συγκρίνεις κείμενο με αριθμό. Ξέχασες το int() στο input() — η παγίδα της Ημέρας 2.

          
Το else τρέχει ενώ έγραψα τη σωστή λέξηΟ χρήστης έγραψε Left και εσύ συγκρίνεις με "left". Βάλε .lower().

          
Το or «πάντα» βγαίνει TrueΈγραψες x == 3 or 5. Το 5 μόνο του μετράει ως True. Θέλεις x == 3 or x == 5.

          
Τυπώνει δύο μηνύματα αντί για έναΧρησιμοποίησες δύο if ενώ ήθελες if / elif. Ήθελες μία επιλογή, όχι ανεξάρτητους ελέγχους.

          
SyntaxError στο elifΈβαλες elif μετά το else. Το else είναι πάντα τελευταίο.

        
      

    


    


    
    

      
§14 Ανακεφαλαίωση

      
Κράτησέ το. Από εδώ και πέρα, σχεδόν κάθε πρόγραμμα που θα γράψεις έχει τουλάχιστον ένα if.


      
Οι τρεις μεγάλες ιδέες

      

        
1
Το if ανοίγει ένα code block: ό,τι έχει εσοχή από κάτω τρέχει μόνο αν η συνθήκη είναι αληθής.

        
2
if / elif / else = μία επιλογή από πολλές, σταματάει στην πρώτη αληθή. Πολλά if στη σειρά = ανεξάρτητοι έλεγχοι, τρέχουν όλοι.

        
3
Ζωγράφισε το διάγραμμα ροής πριν γράψεις κώδικα. Αν δεν βγαίνει στο χαρτί, δεν θα βγει ούτε στον υπολογιστή.
