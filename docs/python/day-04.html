§2 Το random module — δανείζομαι κώδικα

      
Η Python από μόνη της δεν ξέρει να ρίχνει ζάρια. Ξέρει όμως να δανείζεται. Ένα module είναι ένα αρχείο με έτοιμο κώδικα που έγραψε κάποιος άλλος — και με μία γραμμή γίνεται δικός σου:


      
import random

dice = random.randint(1, 6)
print(dice)


      
Τρέξ' το πέντε φορές. Κάθε φορά άλλος αριθμός. Αυτό είναι το πρώτο σου πρόγραμμα που δεν κάνει το ίδιο πράγμα δύο φορές.


      
Τα τρία εργαλεία που θα χρησιμοποιείς

      

        
ΕντολήΤι δίνειΠαράδειγμα

        
          
random.randint(a, b)ακέραιο από a μέχρι και brandint(1, 6) → ζάρι

          
random.random()δεκαδικό από 0.0 μέχρι (αλλά όχι) 1.0random() * 100 → 0 έως 99.99

          
random.choice(list)ένα τυχαίο στοιχείο από λίσταθα το δούμε στην §5

        
      


      

        
Γιατί random.randint και όχι σκέτο randint; Το randint ζει μέσα στο module random. Η τελεία διαβάζεται «από το random, πάρε το randint». Χωρίς το random. μπροστά, η Python δεν ξέρει για τι μιλάς → NameError.

      


      
Κορώνα ή γράμματα

      
Δύο αποτελέσματα, ένας τυχαίος αριθμός, ένα if από την Ημέρα 3:


      
import random

coin = random.randint(0, 1)

if coin == 1:
    print("Heads")
else:
    print("Tails")


      

        
Μην ονομάσεις ΠΟΤΕ το αρχείο σου random.py. Η Python θα κάνει import το δικό σου αρχείο αντί για το πραγματικό module, και τίποτα δεν θα δουλεύει — χωρίς να καταλαβαίνεις γιατί. Είναι ένα από τα πιο μπερδευτικά σφάλματα που υπάρχουν, και τώρα το ξέρεις πριν το πάθεις.

      


      

        
Pseudo-random. Ο υπολογιστής δεν μπορεί να κάνει κάτι πραγματικά τυχαίο — είναι μηχανή που ακολουθεί κανόνες. Υπολογίζει αριθμούς που μοιάζουν τυχαίοι, ξεκινώντας συνήθως από το ρολόι της στιγμής. Γι' αυτό λέγονται ψευδο-τυχαίοι. Για ζάρια και παιχνίδια, αρκούν και περισσεύουν.

§4 Λίστες — πολλές τιμές, ένα όνομα

      
Μια μεταβλητή κρατάει μία τιμή. Μια λίστα κρατάει πολλές, με τη σειρά, κάτω από ένα όνομα. Οι αγκύλες [ ] είναι το σήμα της:


      
fruits = ["apple", "banana", "cherry"]
numbers = [3, 7, 11, 42]
mixed = ["Athens", 13, 1.62, True]

print(fruits)
print(fruits[0])      # apple
print(fruits[1])      # banana
print(fruits[-1])     # cherry  — το τελευταίο
print(len(fruits))    # 3


      
Σου θυμίζει κάτι; Την Ημέρα 2 έκανες name[0] για το πρώτο γράμμα. Ίδιος ακριβώς κανόνας: η αρίθμηση ξεκινάει από το 0. Οι προγραμματιστές το λένε offset — πόσα βήματα από την αρχή. Το πρώτο στοιχείο είναι μηδέν βήματα μακριά.


      

        
Στοιχείο"apple""banana""cherry"

        
          
Index από την αρχή012

          
Index από το τέλος-3-2-1

        
      


      
Αλλαγή στοιχείου

      
fruits = ["apple", "banana", "cherry"]
fruits[1] = "mango"
print(fruits)         # ['apple', 'mango', 'cherry']

      
Η λίστα δεν είναι παγωμένη. Δείχνεις μια θέση, της δίνεις νέα τιμή. Αυτό δεν γίνεται με τα strings — δοκίμασε name[0] = "X" και δες τι λέει η Python.

    


    


    
    

      
§5 append, len και το IndexError


      
fruits = ["apple", "banana", "cherry"]

fruits.append("kiwi")                # ένα στοιχείο στο τέλος
print(fruits)                        # ['apple', 'banana', 'cherry', 'kiwi']

fruits.extend(["mango", "fig"])      # πολλά στοιχεία στο τέλος
print(len(fruits))                   # 6


      
Το .append() είναι σαν το .lower() της Ημέρας 3: μια ενέργεια που ανήκει στο αντικείμενο. Η λίστα ξέρει να προσθέτει στον εαυτό της.


      
Το λάθος με το δικό του όνομα

      
fruits = ["apple", "banana", "cherry"]
print(fruits[3])      # IndexError: list index out of range


      
Τρία στοιχεία → θέσεις 0, 1, 2. Η θέση 3 δεν υπάρχει. Το τελευταίο έγκυρο index είναι πάντα len(list) - 1. Αυτό το bug είναι τόσο συχνό που έχει δικό του όνομα: off-by-one error. Θα το κάνεις. Όλοι το κάνουν. Το θέμα είναι να το αναγνωρίζεις σε τρία δευτερόλεπτα.


      
Ποιος πληρώνει;

      
Μια παρέα, ένας λογαριασμός, και ο υπολογιστής διαλέγει:


      
import random

names_string = input("Give me everybody's names, separated by a comma. ")
names = names_string.split(", ")

person = random.choice(names)
print(f"{person} is going to buy the meal today!")


      
Δύο νέα πράγματα. Το .split(", ") κόβει ένα string σε λίστα, εκεί που βρίσκει κόμμα-και-κενό: το "Maria, Nikos, Eleni" γίνεται ["Maria", "Nikos", "Eleni"]. Και το random.choice() διαλέγει ένα τυχαίο στοιχείο. Αυτές οι δύο γραμμές είναι ο σκελετός κάθε «ποιος θα…» προγράμματος που θα φτιάξεις ποτέ.


      

        
Ο ίδιος στόχος, χωρίς το choice:

        
how_many = len(names)
random_index = random.randint(0, how_many - 1)
print(names[random_index])

        
Γιατί - 1; Γιατί αν η παρέα έχει 3 άτομα, τα index είναι 0, 1, 2 — και το randint(0, 3) θα έβγαζε κάποια στιγμή 3, δηλαδή IndexError. Το random.choice() το κάνει αυτό για σένα. Αλλά τώρα ξέρεις τι κάνει.

      

    


    


    
    

      
§6 Nested lists — λίστα μέσα σε λίστα

      
Μια λίστα μπορεί να περιέχει ό,τι θέλεις — και άλλες λίστες. Έτσι φτιάχνονται πίνακες, χάρτες, σκακιέρες:


      
fruits = ["apple", "banana", "cherry"]
vegetables = ["carrot", "spinach", "onion"]

food = [fruits, vegetables]

print(food)
print(food[1])          # ['carrot', 'spinach', 'onion']
print(food[1][0])       # carrot


      
Διαβάζεται από αριστερά προς τα δεξιά: food[1] είναι τα λαχανικά, και από αυτά, [0] είναι το πρώτο. Δύο ζευγάρια αγκύλες = δύο επίπεδα βάθους. Σαν να ανοίγεις ένα κουτί που έχει μέσα κουτιά.


      
Ο χάρτης του θησαυρού

      
Τρεις γραμμές, τρεις στήλες, ένας θησαυρός. Ο χρήστης λέει πού — π.χ. B2 — και εμείς βάζουμε το X:


      
row1 = [".", ".", "."]
row2 = [".", ".", "."]
row3 = [".", ".", "."]
grid = [row1, row2, row3]

print(f"{row1}\n{row2}\n{row3}")
position = input("Where do you want to put the treasure? (e.g. B2) ")

column = "ABC".index(position[0].upper())    # A→0, B→1, C→2
row = int(position[1]) - 1                    # 1→0, 2→1, 3→2

grid[row][column] = "X"

print(f"{row1}\n{row2}\n{row3}")


      
Το "ABC".index("B") ρωτάει «σε ποια θέση είναι το B μέσα στο ABC;» και απαντάει 1. Ένα string ξέρει να ψάχνει τον εαυτό του — ακριβώς όπως η λίστα ξέρει να προσθέτει στον εαυτό της.


      

        
Πρόσεξε το - 1 ξανά. Ο άνθρωπος μετράει γραμμές 1, 2, 3. Η Python μετράει 0, 1, 2. Κάθε φορά που ο χρήστης δίνει αριθμό θέσης, κάπου θα χρειαστεί ένα - 1. Αν το X βγαίνει μία γραμμή πιο κάτω απ' ό,τι ζήτησες, αυτό ξέχασες.

      


      

        
Θέλεις να φαίνεται καλύτερα; Αντικατέστησε το "." με "⬜" και το "X" με "💎". Αν το Thonny σου δείχνει περίεργα σύμβολα αντί για εικονίδια, γύρνα στις τελείες — δεν φταίει ο κώδικάς σου.

§8 Project — Πέτρα-Χαρτί-Ψαλίδι

      
Ο χρήστης διαλέγει, ο υπολογιστής διαλέγει τυχαία, και το πρόγραμμα κρίνει. Όλα όσα έμαθες μέχρι σήμερα, σε ένα παιχνίδι.


      
Βήμα 0 — ο πίνακας πριν τον κώδικα

      
Πάρε χαρτί. Ζωγράφισε έναν πίνακα 3×3: εσύ στις γραμμές (πέτρα, χαρτί, ψαλίδι), ο υπολογιστής στις στήλες. Σε κάθε κελί γράψε Win, Lose ή Draw. Εννιά κελιά. Αυτός ο πίνακας είναι το πρόγραμμα — ό,τι γράψεις μετά, απλώς τον αντιγράφει.


      
Βήμα 1 — τα τρία σύμβολα, σε μια λίστα

      
Θυμήσου το r''' από την Ημέρα 3 — για ASCII art με ανάποδες καθέτους. Σχεδίασε δικά σου· αυτά είναι μόνο για να ξεκινήσεις:


      
import random

rock = r'''
    _______
   /       \
  |  (   )  |
   \_______/
'''

paper = r'''
   _________
  |         |
  |         |
  |_________|
'''

scissors = r'''
   O   O
    \ /
     X
    / \
'''

choices = [rock, paper, scissors]


      
Η λίστα choices είναι το κόλπο της ημέρας. Η πέτρα είναι στη θέση 0, το χαρτί στην 1, το ψαλίδι στη 2. Κράτα το στο μυαλό σου.


      
Βήμα 2 — ο χρήστης διαλέγει

      
user_choice = int(input("What do you choose? Type 0 for Rock, 1 for Paper or 2 for Scissors.\n"))
print(choices[user_choice])

      
Τρέξ' το. Γράψε 0 — βλέπεις την πέτρα. Ο αριθμός που πληκτρολογεί ο χρήστης γίνεται απευθείας index στη λίστα. Καμία if. Αυτό είναι που κάνει τις λίστες τόσο χρήσιμες: ένας αριθμός διαλέγει.


      
Βήμα 3 — ο υπολογιστής διαλέγει

      
computer_choice = random.randint(0, 2)
print("Computer chose:")
print(choices[computer_choice])

      
Γιατί randint(0, 2) και όχι (0, 3); Αν δεν ξέρεις, ξαναδιάβασε την §5.


      
Βήμα 4 — ποιος κέρδισε;

      
Εδώ ανοίγεις τον πίνακα του Βήματος 0 και τον αντιγράφεις γραμμή-γραμμή:

      
if user_choice == computer_choice:
    print("It's a draw!")
elif user_choice == 0 and computer_choice == 2:
    print("You win! Rock crushes scissors.")
elif user_choice == 1 and computer_choice == 0:
    print("You win! Paper covers rock.")
elif user_choice == 2 and computer_choice == 1:
    print("You win! Scissors cut paper.")
else:
    print("You lose!")

      
Τρεις τρόποι να κερδίσεις, ένας να ισοφαρίσεις, και όλα τα υπόλοιπα είναι ήττα. Το else στο τέλος πιάνει τα τρία κελιά «Lose» με μία γραμμή.


      
Βήμα 5 — τι γίνεται αν ο χρήστης γράψει 7;

      
Θα σκάσει με IndexError στο Βήμα 2. Ένα καλό πρόγραμμα δεν σκάει. Τύλιξε όλα τα βήματα 2–4 σε ένα if:

      
user_choice = int(input("What do you choose? Type 0 for Rock, 1 for Paper or 2 for Scissors.\n"))

if user_choice < 0 or user_choice > 2:
    print("Invalid number, you lose!")
else:
    print(choices[user_choice])
    computer_choice = random.randint(0, 2)
    print("Computer chose:")
    print(choices[computer_choice])

    if user_choice == computer_choice:
        print("It's a draw!")
    elif user_choice == 0 and computer_choice == 2:
        print("You win! Rock crushes scissors.")
    elif user_choice == 1 and computer_choice == 0:
        print("You win! Paper covers rock.")
    elif user_choice == 2 and computer_choice == 1:
        print("You win! Scissors cut paper.")
    else:
        print("You lose!")


      

        
Το κόλπο των μαθηματικών — για αργότερα. Όλα τα «You win» της Βήματος 4 έχουν κάτι κοινό: (user_choice - computer_choice) % 3 βγαίνει πάντα 1. Δοκίμασέ το με τα τρία ζευγάρια. Κάποιος που το βλέπει αυτό, γράφει τη νίκη σε μία γραμμή αντί για τρεις. Δεν χρειάζεται να το χρησιμοποιήσεις σήμερα — αλλά αξίζει να το δεις.

      


      

        
Δικό σου τώρα. Δικό σου ASCII art, δικά σου μηνύματα νίκης — στα ελληνικά αν θέλεις. Κι ένα βήμα παραπάνω: πρόσθεσε τέταρτη επιλογή, λάβα, που νικάει πέτρα και ψαλίδι αλλά χάνει από χαρτί. Πόσα κελιά έχει ο νέος πίνακας; Ζωγράφισέ τον πρώτα.

import random

answers = [
    "Yes, definitely.",
    "It is certain.",
    "Signs point to yes.",
    "Ask again later.",
    "Cannot predict now.",
    "Don't count on it.",
    "My reply is no.",
    "Very doubtful.",
]

question = input("Ask the Magic 8-Ball a yes/no question: ")
print(f"The Magic 8-Ball says: {random.choice(answers)}")

          
Πρόσεξε πώς γράφεται μια μεγάλη λίστα: ένα στοιχείο ανά γραμμή, με κόμμα μετά από κάθε ένα. Η Python δεν νοιάζεται για τις αλλαγές γραμμής μέσα στις αγκύλες.

You rolled 4 and 4 — a double! Total: 8

dice1 = random.randint(1, 6)
dice2 = random.randint(1, 6)
total = dice1 + dice2

if dice1 == dice2:

else:

Επέκταση: πόσο συχνά έρχονται διπλές; Τρέξ' το 20 φορές και μέτρα. Μετά σκέψου: από τα 36 δυνατά ζευγάρια, πόσα είναι διπλές;

§11 AI Corner — το πιο χαζό language model του κόσμου

      
Θυμάσαι την άσκηση Α5; Τρεις λίστες αντί για δύο, και φτιάχνεις προτάσεις:


      
import random

subjects = ["Ο δράκος", "Η γάτα", "Ένα ρομπότ", "Η δασκάλα"]
verbs = ["έφαγε", "ζωγράφισε", "έχασε", "βρήκε"]
objects = ["ένα κάστρο", "τον ήλιο", "ένα παλιό κλειδί", "μια πίτσα"]

sentence = f"{random.choice(subjects)} {random.choice(verbs)} {random.choice(objects)}."
print(sentence)


      
Μόλις έφτιαξες ένα πρόγραμμα που παράγει κείμενο. Είναι χαζό — δεν ξέρει τι λέει — αλλά η βασική ιδέα είναι ακριβώς ίδια με αυτό που κάνει το ChatGPT ή το Gemini: διαλέγει την επόμενη λέξη από μια λίστα. Οι διαφορές είναι τρεις:

      
    
        
  • Η λίστα του δεν έχει 4 λέξεις. Έχει γύρω στα 100.000 κομμάτια λέξεων — τα tokens που είδες την Ημέρα 2.
    • 
        
  • Δεν διαλέγει με ίσες πιθανότητες. Κάθε λέξη έχει ένα βάρος, ανάλογα με όλα όσα προηγήθηκαν. Μετά το «Η γάτα», το «νιαούρισε» έχει μεγάλο βάρος, το «απογειώθηκε» μικρό.
    • 
        
  • Τα βάρη δεν τα έγραψε άνθρωπος. Τα έμαθε διαβάζοντας εκατομμύρια βιβλία και σελίδες. Αυτό λέγεται training.
    • 
      


      
Το δεύτερο σημείο μπορείς να το δεις με τα μάτια σου. Η Python έχει μια αδερφή του choice που δέχεται βάρη:


      
next_word = random.choices(["νιαούρισε", "κοιμήθηκε", "απογειώθηκε"], weights=[60, 35, 5])
print(next_word[0])

# Τρέξ' το 20 φορές. Σχεδόν πάντα "νιαούρισε" ή "κοιμήθηκε".
# Σπάνια, μία στις είκοσι, η γάτα απογειώνεται.


      
Πρόσεξε: choices με s στο τέλος, και επιστρέφει λίστα — γι' αυτό το [0]. Αυτό το weights είναι το μισό μυστικό των σύγχρονων AI. Το άλλο μισό — πώς βρίσκονται οι αριθμοί 60, 35, 5 — είναι το training, και θα το δούμε από κοντά αργότερα μέσα στη χρονιά.


      

        
Η ερώτηση που μετράει: Ρώτα το ίδιο πράγμα σε ένα AI δύο φορές — π.χ. «γράψε μου μία πρόταση για μια γάτα». Πήρες την ίδια απάντηση; Σχεδόν ποτέ. Τώρα ξέρεις γιατί: κάπου μέσα του υπάρχει ένα random.choices(). Οι μηχανικοί το ρυθμίζουν με μια τιμή που λέγεται temperature — πόσο «τολμηρό» να είναι στις επιλογές του. Χαμηλή temperature → πάντα η πιο πιθανή λέξη, σχεδόν ίδια απάντηση κάθε φορά. Ψηλή → τρελές επιλογές, σαν τη γάτα που απογειώθηκε.

      

    


    


    
    

      
§12 Συχνά λάθη

      
Όταν σκάσει κάτι, ψάξ' το εδώ πρώτα.

      

        
ErrorΤι φταίει

        
          
NameError: name 'random' is not definedΞέχασες το import random στην πρώτη γραμμή.

          
NameError: name 'randint' is not definedΈγραψες σκέτο randint. Θέλει random.randint — από το module, πάρε τη συνάρτηση.

          
AttributeError: module 'random' has no attribute 'randInt'Κεφαλαίο I. Είναι randint, όλα πεζά.

          
AttributeError σε κάθε εντολή του randomΤο αρχείο σου λέγεται random.py. Μετονόμασέ το σε οτιδήποτε άλλο.

          
IndexError: list index out of rangeΖήτησες θέση που δεν υπάρχει. Λίστα με 3 στοιχεία → μόνο 0, 1, 2. Το τελευταίο είναι len - 1.

          
TypeError: list indices must be integers or slices, not strΈγραψες fruits["1"] ή ξέχασες το int() στο input(). Το index είναι αριθμός.

          
Η λίστα μου έγινε NoneΈγραψες fruits = fruits.append("x"). Το append αλλάζει τη λίστα επί τόπου και δεν επιστρέφει τίποτα. Σκέτο fruits.append("x").

          
ValueError: substring not foundΤο "ABC".index("D") — ο χρήστης έγραψε γράμμα που δεν υπάρχει στον χάρτη. Θυμήσου το else της Ημέρας 3.

          
Το randint(1, 10) έβγαλε 10Δεν είναι λάθος. Το randint περιλαμβάνει και τα δύο άκρα. Αν ήθελες 1–9, γράψε randint(1, 9).

        
      

    


    


    
    

      
§13 Ανακεφαλαίωση

      
Κράτησέ το. Οι λίστες είναι η δομή που θα χρησιμοποιείς περισσότερο από οτιδήποτε άλλο από εδώ και πέρα.


      
Οι τρεις μεγάλες ιδέες

      

        
1
Το import φέρνει έτοιμο κώδικα. Το module.function() διαβάζεται «από εκεί, πάρε αυτό».

        
2
Λίστα = πολλές τιμές, ένα όνομα, θέσεις από το 0. Το τελευταίο στοιχείο είναι στη θέση len - 1.

        
3
random.choice(list) — ο σκελετός κάθε παιχνιδιού που θα φτιάξεις φέτος. Ένας αριθμός διαλέγει.
